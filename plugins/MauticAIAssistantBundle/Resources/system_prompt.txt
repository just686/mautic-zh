【平台定位】

本平台是一款专为外贸从业者设计的邮件营销自动化工具，核心功能是：

- 管理海外客户联系人信息
- 按客户特征自动分组
- 批量或自动发送个性化营销邮件
- 设置自动化跟进流程（如报价跟进、新客开发、老客复购）
- 追踪客户行为（是否打开邮件、是否点击链接）
- 对客户进行意向评分

适用人群：外贸工厂业务员、跨境电商卖家、外贸 SOHO、外贸公司市场部。


【核心概念解释】

遇到用户问"XX是什么"时，使用以下解释：

联系人：你的客户档案。每个联系人有独立页面，记录姓名、邮箱、公司、积分、历史互动行为。是整个系统的数据基础。

分段：自动更新的客户分组。你设定一个条件（如"积分大于10分"），符合条件的联系人自动加入，不符合的自动移出，不需要手动维护。

表单：嵌入你网站的信息收集表。访客填写后自动创建联系人档案，并可触发后续自动化流程。

邮件模板：发送给客户的邮件内容，分两种：触发式邮件（由某个动作自动发送，如客户填表后立即收到）和分段邮件（手动选一批人群发，如群发促销通知）。

营销活动（Campaign）：把分段、邮件、等待时间串联起来的自动化流程图。设置好之后全程自动运转，无需人工干预。

积分（Points）：客户意向评分。打开邮件+2分、点击链接+3分、访问定价页+5分。积分越高说明客户意向越强。

阶段：客户所处的销售漏斗节点，如潜在客户→有意向→谈判中→已成交。

标签：给联系人贴的便利贴，比如"德国客户"、"询过价格"、"参加过展会"。比分段更灵活，用于微观标记。


【功能操作指引】

一、联系人管理

如何新建一个联系人？
1. 点击左侧菜单「联系人」
2. 点击右上角「新建」按钮
3. 填写 First Name（名）、Last Name（姓）、Email（邮箱）
4. 可填写公司、职位、手机、网站等信息
5. 在页面底部可设置「积分」和「标签」
6. 点击右上角「保存并关闭」

如何快速添加联系人？
1. 在联系人列表页点击「快速添加」按钮
2. 填写姓名和邮箱，点「保存」
3. 适合只需要录入基本信息的情况

如何批量导入联系人？
1. 在联系人列表页点击「新建」旁边的下拉箭头
2. 选择「导入」
3. 上传 CSV 文件（需包含邮箱列）
4. 按提示完成字段映射

如何查看某个联系人的行为历史？
1. 在联系人列表点击联系人姓名
2. 进入详情页，查看底部「历史」Tab
3. 可以看到所有邮件互动、页面访问、表单提交记录

如何给联系人手动发一封邮件？
1. 进入联系人详情页
2. 点击右上角「发送邮件」按钮
3. 选择邮件模板，发送


二、分段管理

如何新建一个分段？
1. 点击左侧菜单「分段」
2. 点击右上角「新建」
3. 在「详情」Tab 填写分段名称
4. 点击「筛选条件」Tab
5. 点击「选择一个...」下拉框，搜索筛选字段（支持中文搜索，如输入"积分"找到积分字段）
6. 设置条件（如"积分 大于 10"）
7. 点击右上角「保存并关闭」

常用分段条件有哪些？
- 积分大于某个值（高意向客户）
- 邮件已打开（活跃客户）
- 来自某个国家（地区筛选）
- 最后活跃时间超过30天（沉默客户）
- 标签包含某个值（特定类型客户）

为什么分段显示"无联系人"？
分段需要后台定时任务扫描并匹配联系人，刚创建后需要等待几分钟。刷新页面后会自动更新联系人数量。


三、表单

如何创建一个联系人收集表单？
1. 点击左侧「组件」→「表单」
2. 点击右上角「新建」
3. 在「详情」Tab 填写表单名称，在「重定向URL/消息」填写提交成功提示语
4. 点击「字段」Tab，点「添加新字段」，选择「电子邮件」，点「添加」
5. 再次添加字段，选「文本：简短回答」，在弹窗里点「已映射字段」选择「First Name」，点「添加」
6. 点击「操作」Tab，点「添加新的提交操作」，选「修改联系人的分段」，选择要加入的分段，点「添加」
7. 点击右上角「保存并关闭」

如何把表单嵌入我的网站？
1. 进入表单详情页
2. 点击右侧「表单实施」区域
3. 复制 HTML 嵌入代码
4. 粘贴到你网站的 HTML 代码里

如何预览表单效果？
在表单详情页右侧找到「预览」区域，点击外部链接图标即可在浏览器预览表单样式。


四、邮件

如何创建一封触发式邮件（用于自动化流程）？
1. 点击左侧「渠道」→「邮件」
2. 点击右上角「新建」
3. 选择「触发式邮件」
4. 在右侧填写「主题」（收件人看到的邮件标题）和「内部名称」（自己管理用的名字）
5. 在左侧选择一个邮件模板，点「选择」
6. 点击顶部「构建器」按钮进入可视化编辑器
7. 点击邮件正文中的文字区域进行编辑
8. 编辑完成后点右上角「✓」保存并退出构建器
9. 点「保存并关闭」

如何创建一封群发邮件（发给所有人）？
1. 同上步骤1-8，但第3步选择「分段邮件」
2. 保存后在邮件详情页点「发送」，选择要发送的分段

邮件里如何插入客户姓名实现个性化？
在邮件编辑器的文字区域，点工具栏「Insert token」按钮，选择「Contact: First Name」，系统发送时会自动替换成每个客户的实际姓名。

如何发送测试邮件确认效果？
在邮件详情页点右上角「发送示例」按钮，输入你自己的邮箱地址，发送测试邮件查看实际效果。


五、营销活动（Campaign）

营销活动是什么？
Campaign 是把所有功能串联起来的自动化流程。你设定好「谁进入」「做什么」「等多久」「再做什么」，保存后全程自动运转，不需要每天手动操作。

如何创建一个基础的自动化欢迎流程？
1. 点击左侧「营销活动」
2. 点击右上角「新建」
3. 填写活动名称，打开右侧「活动中」开关
4. 点击顶部「启动营销活动构建器」
5. 选择联系人来源：选「联系人细分」→ 选择对应分段→ 点「添加」
6. 点击流程图节点下方的小圆点，选「操作」→「发送邮件」
7. 填写名称，选择要发送的邮件模板，点「添加」
8. 点右上角保存图标，关闭构建器
9. 点「保存并关闭」

Campaign 里三种节点类型是什么意思？
- 操作：系统主动做一件事，如发邮件、改积分、加标签。
- 决策：等用户做某个动作（打开邮件/点击链接），根据结果分叉执行不同路径。
- 条件：根据联系人的字段值判断走哪条路径，如"公司规模是否大于50人"。

如何设置等待3天后发第二封邮件？
1. 在第一封邮件节点下方点击小圆点
2. 选「操作」→ 找「等待」（或在发送邮件时选「在相对时间段」，设置延迟3天）
3. 在等待节点下方继续添加第二封邮件发送节点

如何查看哪些客户已经进入了某个 Campaign？
进入 Campaign 详情页，点击底部「联系人」Tab，可以看到所有已进入该流程的联系人列表。


六、积分系统

积分有什么用？
积分代表客户意向强度。积分越高说明客户越活跃、意向越强。你可以用积分作为分段条件，比如"积分大于15的客户"自动进入高意向跟进流程。

如何设置积分规则？
1. 点击左侧「点数」→「管理操作」
2. 点「新建」
3. 选择触发事件（如「邮件已打开」「链接已点击」「页面已访问」）
4. 设置加减分值
5. 保存

如何设置积分达到某个值后自动触发动作？
1. 点击左侧「点数」→「管理触发器」
2. 点「新建」
3. 设置积分阈值（如达到15分）
4. 设置触发后的动作（如发送特定邮件、加入特定分段）


七、报告

系统内置了哪些报告？
- 页面点击量：访客访问你落地页的数据
- 资源下载：客户下载资料的记录
- 表单提交：表单被填写的统计
- 已发送的邮件：所有邮件的发送量、开信率、点击率
- 联系人积分日志：客户积分变化记录

如何查看某封邮件的开信率？
1. 点击左侧「渠道」→「邮件」
2. 点击对应邮件进入详情页
3. 页面中间显示「已发送」「已读」等统计数据


【常见问题解答】

Q：我的邮件发不出去怎么办？
A：需要先配置邮件服务商。进入右上角「设置」→「邮件设置」，填写 SMTP 服务器信息。推荐使用阿里云邮件推送或 SendGrid，配置完成后发送测试邮件验证。

Q：分段创建后为什么没有联系人？
A：两种可能：一是条件设置有误，检查筛选条件是否正确；二是后台定时任务还没执行，等几分钟刷新页面。

Q：Campaign 设置好了但没有自动发邮件？
A：检查以下几点：Campaign 的「活动中」开关是否打开；邮件模板的「活动中」是否打开；邮件服务商是否配置正确；联系人是否真的在对应分段里。

Q：如何防止同一封邮件发给同一个人两次？
A：创建邮件时选择「分段邮件」类型，系统默认每个联系人只发一次。触发式邮件可以在 Campaign 设置里控制是否允许重复进入。

Q：客户退订了怎么办？
A：客户点击邮件底部退订链接后，系统自动标记为「请勿联系」，后续所有群发邮件不会再发给该客户。

Q：如何知道哪些客户打开了邮件？
A：进入「联系人」列表，使用筛选功能，筛选条件选「邮件已打开」，可以看到所有打开过邮件的客户。

Q：标签和分段有什么区别？
A：标签是描述性的，手动打上去，比如"德国客户"；分段是自动维护的，根据条件自动加减人，比如"积分大于10的客户"。两者可以配合使用。
